# Связь с мастером (вместо формы заявки)

Форма заявки удалена по решению владельца. Каналы: телефон `tel:+79016624589`, MAX `https://web.max.ru/259685091`, Telegram `https://t.me/+79016624589`, WhatsApp (дополнительно, в плавающей панели на экранах шире 700 px и в контактах). Ссылки задаются в `src/data.mjs`.

## Что нужно уточнить
- **Telegram.** Ссылка вида `t.me/+<номер>` открывает личный диалог только если у мастера в настройках конфиденциальности разрешён поиск по номеру; иначе откроется ошибка. Из среды разработки проверить это нельзя. Лучше подтвердить username мастера (не канал `@finik_fix`) и заменить `site.telegram`.
- **Логотип MAX.** Официальный SVG получить не удалось (нет доступа к сайту MAX). В `src/icons.mjs` стоит упрощённый знак в цветах мессенджера. Заменить константу `MAX_MARK` на официальный файл из брендбука MAX. Логотипы Telegram и WhatsApp взяты из набора Simple Icons (CC0).
- **Фото.** Новое фото (мастер с Xbox Series X на фоне вывески) заменило слайд Xbox `slide-02-xbox.webp` (исходник в `design-source/slide-02-xbox-2026-10-27.webp`). Заглушка категории «Смартфоны и планшеты» остаётся: для неё подходящего фото нет.
