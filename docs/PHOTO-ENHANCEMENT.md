# FinikFix — автоматический показ и HD-фотографии

## Что работает без платных сервисов

- Главный слайдер запускается автоматически при открытии страницы, интервал **5 секунд**.
- Наведение курсора НЕ останавливает автопоказ. Кнопка паузы, переход стрелками, точки и свайпы сохранены.
- Если в ОС включено **«Уменьшение движения»**, автоматический показ не стартует до нажатия кнопки «Запустить» — требование доступности.
- При переходе на другую вкладку и при прокрутке слайдера за пределы экрана автопоказ временно приостанавливается.
- В окне просмотра нескольких фотографий портфолио автопоказ также запускается при открытии (5 секунд), а при закрытии останавливается.
- При наличии HD-файла браузер сначала показывает оригинал, затем подгружает HD. При ошибке оставляет оригинал и сообщает о проблеме.

## Зачем делать HD-файлы до публикации

Текущие шесть WebP-слайдов были сохранены с сильным сжатием и шириной около 1600 px (Xbox уже имел ширину ~1360 px). На широких экранах и при DPR=2 браузер растягивает их и становятся заметны артефакты.
Простая CSS-резкость не восстановит удалённые детали; даже AI-модель может изменить лицо и буквы вывески. Проверяйте полученные файлы визуально.

Название «клоу Дейзинг» не удалось идентифицировать по официальной документации. В качестве **отдельной, необязательной** и документированной интеграции добавлена Claid.ai Image Edit Upload API.
Она не запускается без явного создания ключа и команды. **Не утверждать, что это и есть ранее названный пользователем сервис.**

Официальная документация: https://docs.claid.ai/image-editing-api/upload-api-reference

## Как включить обработку через Claid.ai

1. Зарегистрируйте аккаунт на https://claid.ai и создайте API key; проверьте стоимость/кредиты. Не сообщайте ключ в чат и не сохраняйте в Git.
2. В терминале на компьютере разработчика передайте ключ через временную переменную окружения.
   - PowerShell 5.1/7: `$secure = Read-Host 'Claid API key' -AsSecureString; $env:CLAID_API_KEY = (New-Object System.Net.NetworkCredential('x', $secure)).Password`
   - Bash: `read -rsp 'Claid API key: ' CLAID_API_KEY; echo; export CLAID_API_KEY`
3. Выполните `npm run enhance:photos`.
   - Для одного фото: `npm run enhance:photos -- --only=slide-02-xbox.webp`
   - Пересоздать уже улучшенные: `npm run enhance:photos -- --force`.
4. Посмотрите результаты и визуально сравните лицо мастера, надписи FinikFix и технику.
5. Закоммитьте проверенные файлы из `src/assets/img/slides-hq/`, `cats-hq/`, `portrait-hq/` и запустите стандартный CI/ручной деплой.
6. Удалите переменную после обработки (`Remove-Item Env:CLAID_API_KEY` в PowerShell или `unset CLAID_API_KEY` в Bash).

Скрипт обрабатывает шесть слайдов (до 2560 px по ширине), шесть карточек категорий (до 1600 px) и фотографию мастера (до 2048 px). Категория смартфонов не имеет изображения и пропускается.

Результат всегда сохраняется **отдельно** от исходников. Уже подготовленные файлы пропускаются без `--force`. При сбое сервиса и недоступности ключа сайт продолжает показывать исходные фотографии.

### Защита

- Ключ присутствует только в переменной `CLAID_API_KEY`; не передаётся браузеру и не сохраняется в исходниках.
- Основной билд `npm run build` и GitHub Actions не вызывают сторонний API.
- Внешняя обработка расходует кредиты только при явном запуске `npm run enhance:photos`.
- Подгрузка HD является необязательной и не блокирует первый показ картинки.
- Для фотографий из админки/портфолио поле `enhancedSrc` поддерживается просмотрщиком, если backend в будущем передаст ссылку на проверенный HD-файл. Автоматической обработки новых пользовательских загрузок пока нет: требует отдельного согласования поставщика и политики обработки файлов.
